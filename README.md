# OmniTrack AI (Mission Foundation)

This repository contains the foundational domain modules for **OmniTrack AI**, a unified macro + micronutrient coaching platform inspired by MacroFactor, Cronometer, and Fitia workflows.

## Run

```bash
npm test
npm run demo
```

## Included Capabilities

- Adaptive coaching engine with weekly TDEE updates and non-shaming UX flags.
- Clinical nutrient registry requiring USDA/NCCDB sources and 80+ micronutrients.
- Multimodal meal logging contracts (photo, voice, barcode).
- Specialized protocol manager (keto, intermittent fasting, peri-workout).
- Weekly meal planner + shopping list generation.
- Ecosystem sync abstraction for Health Connect, Apple Health, Garmin Connect+.
- Mission Control feedback store for iterative UI reviews.

See `docs/` for architecture, implementation plan, and verification walkthroughs.
